# Para Sofía · S&N

Sitio web estático listo para abrir o publicar en GitHub Pages.

## Archivos

- `index.html`: estructura de la página.
- `styles.css`: estilos.
- `app.js`: interacciones.
- `images/`: imágenes usadas por la galería.

## Abrir localmente

Haz doble clic en `index.html` o abre el archivo desde un navegador.
